# Frontend

Next.js (TypeScript) client for the Signal clone. See the [repo root README](../README.md) for setup instructions, architecture, database schema, and the API overview.

Quick start:

```bash
npm install
npm run dev
```

Requires the backend running (see `../backend`) and `NEXT_PUBLIC_API_URL` / `NEXT_PUBLIC_WS_URL` set — copy `.env.example` to `.env.local`.
